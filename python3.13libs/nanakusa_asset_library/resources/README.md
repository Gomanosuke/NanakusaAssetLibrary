# resources

`meadow_2_8k.exr` is the lighting HDR used for generated thumbnails (Dome Light: exposure -0.5, rotated -30 degrees).
It is a large downloaded image, so it is **not tracked by Git** (`*.exr` is ignored). Copy the file into this folder on every PC.
Without it, thumbnails fall back to Houdini's default white Dome Light.
