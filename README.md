# NanakusaAssetLibrary

Houdini 22 の Solaris 向けアセットブラウザーです。USD・3Dモデル・テクスチャを1つのパネルで探し、ドラッグ&ドロップでシーンに取り込めます。素材はプロジェクトとは別の場所にまとめて置くので、どのプロジェクトからも同じライブラリーを使えます。

現在のバージョン: **0.24.0**

## 主な機能

- **一覧と検索**: 素材をサムネイル付きで一覧し、名前・パス・タグで絞り込めます。語の前に `-` を付けると、その語を含む素材を除外できます。タグとお気に入りも付けられます。
- **ドラッグ&ドロップで取り込み**: Solaris（stage）、obj / SOP、パラメーターの入力欄、マテリアルネットワークに落とすと、落とした場所に合うノードを作ります。まとめて落とした場合も、Undo 1回で元に戻せます。
- **PBRテクスチャからマテリアルを作成**: albedo・roughness・normal などの画像をまとめて落とすと、MaterialX のマテリアルを組み立てます。
- **PBRセットのまとめ表示**: 同じ素材の画像を1つのアイコンにまとめて表示します。
- **フォルダーの整理**: パネルの中で素材やフォルダーを移動できます。サムネイル・タグ・お気に入りも一緒に移ります。
- **サムネイルの自動生成**: USD と3Dモデルは Karma でレンダリングしてサムネイルを作ります。
- **Proxy・LOD・バリアント切り替えの追加**: 重い USD に軽い表示用の形状（proxy）や詳細度の段階（LOD）を追加できます。複数のオブジェクトが入ったパックを、1つずつ切り替えて使えるようにもできます。
- **風に揺れるアニメーション**: 植物の USD から、そよ風に揺れ続ける別の USD を作ります。インスタンスでどの向きに置いても自然に見えるように、特定の風向きを持たない揺れにしています。
- **Asset Catalog への登録**: USD を Houdini の Asset Catalog に登録できます。

## 動作環境

- Houdini 22.0（22.0.447 / Windows 11 で動作を確認しています。ほかのOSやバージョンでは試していません）
- インストールには Python 3.10 以上、または Houdini 付属の hython を使います。
- サムネイルの生成と、モデルの情報（ポリゴン数など）の取得には、Houdini と Karma を使えるライセンスが必要です。
- このリポジトリに素材は含まれていません。素材は自分で用意し、リポジトリとは別の場所に置いてください。

## インストール

1. このリポジトリを clone するか、ZIP をダウンロードして展開します。素材を置くフォルダーとは別の場所にしてください。
2. Houdini で作業中のシーンを保存し、Houdini を終了します。
3. hython か Python 3.10 以上で、次のコマンドを実行します。

```text
python install.py --prefs "<Houdiniのユーザー設定フォルダー>" --library "<素材フォルダー>" --data "<データフォルダー>"
```

| 引数 | 内容 |
|---|---|
| `--prefs` | Houdini のユーザー設定フォルダー。通常は `Documents\houdini22.0` です。 |
| `--library` | 素材を置くフォルダー。省略した場合は、あとからパネルで登録できます。 |
| `--data` | 設定・タグ・索引・バックアップの保存先。省略すると、素材フォルダーと同じ階層の `data` になります。 |

4. Houdini を起動し、Python Panel のメニューから **NanakusaAssetLibrary** を開きます。シェルフのボタンや、次の Python からも開けます。

```python
import nanakusa_asset_library
nanakusa_asset_library.show()
```

**更新するとき**は `git pull` のあと Houdini を再起動します。リポジトリのフォルダーを移動した場合は、インストールをやり直してください。

**アンインストールするとき**は `<prefs>/packages/nanakusa_asset_library.json` を削除します。素材と `data` フォルダーは残ります。

フォルダーは次のように分けて置くのがおすすめです。

```text
<好きな場所>/NanakusaAssetLibrary/     # このリポジトリ
<素材の場所>/
  asset/                              # 素材（USD / Texture / 3DModel）
  data/                               # 設定・タグ・索引（PCごとに持つ）
```

素材とサムネイルは複数のPCで共有できます。ただし `data` の中のデータベースは各PCのローカルディスクに置き、複数のPCから同時に書き込まないでください。

## 素材フォルダーの構成

素材フォルダーの直下には `USD`・`3DModel`・`Texture` の3つを置きます。この3つは固定で、その下は自由に整理できます。

```text
asset/
  USD/
    Props/
      Chair/
        Chair.usd          # フォルダーと同じ名前のファイルが入口になる
        thumbnail.png
        textures/
  3DModel/
    Props/
      Mesh.fbx
  Texture/
    PBR/
      stone_1K_albedo.tif
    HDR/
```

### USD

フォルダーと同じ名前の `.usd` / `.usdc` / `.usda` / `.usdz` を入口として、フォルダー全体を1つの素材として扱います。単体の `.usdz` ファイルも一覧に出ます。

フォルダーと同じ名前のファイルがなく、中に複数の USD がある場合は、それぞれを別の素材としてそのフォルダーの中に表示します。大小のサイズ違いが共通の `textures` フォルダーを使う配布素材などが、この形です。こうした素材は同じフォルダーのテクスチャを共有しているため、どれか1つを別のフォルダーへ移動するとフォルダーごと移動します。一緒に移動した素材はステータス欄に表示されます。

### 3DModel

`.obj` `.fbx` `.abc` `.glb` `.stl` `.ply` `.vdb` `.bgeo(.sc)` `.geo(.sc)` など、1つのファイルで形状を読める形式に対応しています。FBX が参照する外部画像や、元のマテリアルは再現しません。

### Texture

PNG・JPEG・TIFF・HDR・EXR などの画像に対応しています。Houdini が元画像の隣に自動で作る変換キャッシュ（`sky_8k.hdr.rat` や `wood.png.tx` のように拡張子が2つ重なったもの）は一覧に出しません。自分で保存した `.rat` や `.tx` は表示します。

### 素材の追加と再スキャン

Houdini を起動して最初にパネルを開いたときは、自動で再スキャンします。Houdini を閉じている間に追加・変更した素材も、このとき反映されます。起動したまま素材を追加した場合は、ツールバー右端の **Rescan** を押してください。スキャンは読み取りだけで、素材ファイルは変更しません。

起動時の自動スキャンが不要なら、`data/settings.json` に `"rescan_on_first_open": false` を書き加えます。

## 画面の見方

| 場所 | 内容 |
|---|---|
| 左 | ライブラリーとフォルダーのツリー、**Libraries...** ボタン（ライブラリーの追加・再リンクなど）、**Catalog** 選択欄 |
| 中央 | 素材の一覧 |
| 右 | 大きなプレビュー、素材の情報、タグ、お気に入り |
| 上 | 検索欄（`Ctrl+F` で移動）、種類フィルター、**Stack PBR Sets**、★Favorites、Options、Rescan |
| 下 | バックグラウンド処理の残り件数と **Cancel All**（処理が残っている間だけ表示） |

検索欄には複数の語をスペースで区切って入力できます。すべての語を名前・パス・タグのどこかに含む素材が表示されます。語の前に `-` を付けると、その語を含む素材を除外します。たとえば `grass -anim` は、grass を含み anim を含まない素材を表示します。大文字と小文字は区別しません。

右の情報欄には、テクスチャなら解像度・チャンネル数・ピクセル形式、3Dモデルと USD ならポリゴン数・頂点数・メッシュ数が出ます。USD ではさらに、proxy の有無、上方向の軸、マテリアル数、バウンディングボックスの大きさも確認できます。

**Cancel All** は待機中の処理をすべて取り消します。実行中の1件だけは最後まで処理します。

### 選択と操作

- `Ctrl` + クリックで追加選択、`Shift` + クリックで範囲選択、`Ctrl+A` で読み込み済みの素材をすべて選択します。
- 素材を右クリックすると、**Import Selected**（取り込み）、**Copy Paths**、**Show in Explorer**、サムネイル生成などのメニューが出ます。USD には **Add Catalog** も出ます。
- **Show in Explorer** は、素材のファイルを選択した状態でエクスプローラーを開きます。
- `Ctrl` を押しながらマウスホイールを回すか、中ボタンでドラッグすると、アイコンの大きさを 64〜512px の範囲で変えられます。大きさは次回も引き継がれます。
- タグは、入力して Enter を押すか入力欄から離れたときに保存されます。お気に入りはチェックを切り替えた時点で保存されます。

### PBRセットのまとめ表示

同じフォルダーにある同じ素材の画像（albedo・roughness・normal など）を、1つのアイコンにまとめて表示します。カードが重なった見た目と、右下の枚数バッジが目印です。フィルターの **Stack PBR Sets** で切り替えます。

まとめたアイコンを選ぶと、中の画像をすべて選んだことになります。ドラッグ・取り込み・パスのコピー・移動・タグ付けは、すべての画像が対象です。

画像のファイル名は `素材名_1K_albedo.tif` のように、末尾にチャンネル名が付いていることを前提にしています。1K と 2K のように解像度が違う画像は別のまとまりになります。同じチャンネルの画像が2枚あるフォルダーはまとめません。

## ドラッグ&ドロップ

一覧から素材をドラッグし、次の場所に落とします。

| 素材 | 落とす場所 | 作られるもの |
|---|---|---|
| 3Dモデル | stage / LOP ネットワーク | SOP Create と、形式に合った読み込み SOP |
| 3Dモデル | obj / SOP ネットワーク | Geometry ノードとその中の読み込み SOP |
| USD | stage / LOP ネットワーク | Reference LOP |
| USD | obj / SOP ネットワーク | USD Import SOP |
| すべて | パラメーターなどの文字列の入力欄 | ファイルパス |
| テクスチャ | Material Library / MaterialX Builder | UV 付きの MaterialX マテリアル |

- 複数の素材をまとめて落とした場合は、Merge ノードで全素材をつなぎます。取り込みは Undo 1回で元に戻せます。
- 入力欄に複数のパスを落とすと、スペース区切りで入ります（空白を含むパスは引用符で囲みます）。1つのファイルしか受け付けない欄には、1つずつ落としてください。
- テクスチャは、マテリアルネットワークか入力欄に落としたときだけ働きます。Scene View など上の表にない場所に落としても、何も起きません。
- 右クリックの **Import Selected** でも同じように取り込めます。単体の USD なら、Options で取り込み先、Reference か Sublayer か、配置先の Prim を指定できます。
- バリアントを持つ USD（`variant` タグ付き）を stage に取り込むと、Reference の下に **Set Variant** ノードが自動で追加されます。バリアントを切り替えたいときは、このノードの Variant Name Index を変えます。
- LOD を持つ USD（`lod` タグ付き）を取り込むと、さらに **Auto Select LOD** ノードも追加されます。

## PBRテクスチャからマテリアルを作る

同じ素材の画像をまとめてマテリアルネットワークに落とすと、MaterialX のマテリアルを1セット作ります。接続先はファイル名に含まれるチャンネル名で決まります。

| ファイル名に含まれる語 | 接続先 |
|---|---|
| albedo / basecolor / diffuse | base_color |
| roughness / rough | specular_roughness |
| metallic / metalness | metalness |
| normal / normalgl / nor_gl | Normal Map → normal |
| height / displacement / disp | Displacement |
| ao / ambient_occlusion | ベースカラーに乗算 |
| opacity / alpha | opacity |
| emission / emissive | emission_color |

- 名前は `_` `-` `.` と空白で区切って読み取ります。大文字と小文字は区別しません。チャンネル名にあたる語が複数あるときは、最後に出てくる語を使います。
- 色の画像は sRGB、HDR と EXR は linear Rec.709、法線や粗さなどのデータ画像は Raw として読み込みます。
- ノードは左から「UV → Image → 変換 → Standard Surface → 出力」の順に並べます。
- 既存の Builder に落とした場合は、既存のノードには触れずに下へ追加します。出力への接続も付け替えないので、必要に応じて手でつないでください。
- 法線マップは OpenGL 形式を前提にしています。DirectX 形式と判定した画像はエラーになるので、変換してから使ってください。
- ORM を1枚にまとめた画像の分解と、UDIM には対応していません。

## フォルダーと素材の整理

エクスプローラーを開かなくても、パネルの中で素材の場所を整理できます。

- **素材を移動する**: 一覧から左のフォルダーへドラッグします。複数選択やPBRセットのまとめもそのまま移動できます。
- **フォルダーを移動する**: 左のフォルダーを別のフォルダーへドラッグします。`Ctrl` / `Shift` + クリックで複数選び、まとめて移動することもできます。

サムネイル・タグ・お気に入りは素材と一緒に移動します。USD を移動したときは、Asset Catalog に登録済みのパスも更新します。

移動先に同じ名前のものがある場合は、上書きせずにエラーにして、何も変更しません。途中で失敗した場合も元の状態に戻します。移動できるのは同じ分類（USD / 3DModel / Texture）の中だけで、USD パッケージの中には入れられません。

移動しても、HIP ファイルや USD レイヤーに書かれたパスは書き換わりません。移動した素材をシーンから参照している場合は、参照先を手で更新してください。

## サムネイル

- **テクスチャ**: 縮小画像を自動で作り、`data/thumbnails` に保存します。
- **USD と3Dモデル**: 右クリックの **Generate Selected Thumbnails** で作ります。**Libraries...** の **Generate Missing Thumbnails** を使うと、表示中の条件に合う素材のうち、サムネイルがないものをまとめて作れます。待機中の分は **Cancel Thumbnails** で取り消せます。

USD と3Dモデルのサムネイルは素材の隣に保存するので、素材と一緒に共有できます。USD は入口ファイルの隣の `thumbnail.png`、3Dモデルは `<モデル名>_thumbnail.png` です。素材フォルダーへの書き込み権限が必要です。

レンダリングは別のプロセスで Karma CPU を使って行います（512×512）。作業中のシーンにノードは追加せず、GPU も使いません。

照明には屋外の HDRI を使いますが、**HDRI はこのリポジトリに含まれていません**。使う場合は、Poly Haven などで配布されている「Meadow 2」の 8K EXR（`meadow_2_8k.exr`）を `python3.13libs/nanakusa_asset_library/resources/` にコピーしてください。ライセンスは配布元で確認してください。HDRI がない場合は白い Dome Light で照らします。

`.usdz` の中にプレビュー画像が入っている場合は、レンダリングせずにその画像を使います。USDZ ファイル自体は変更しません。自分で作ったサムネイルや指定した画像があれば、そちらを優先します。

素材を1つだけ選んで右クリックの **Choose Thumbnail...** を使うと、好きな画像をサムネイルに指定できます。

## Proxy を追加する

proxy（`purpose=proxy`）を持たない USD は、Scene View でもレンダー用の重い形状がそのまま表示されます。この機能は、ポリゴン数を減らした形状を proxy として USD に追加し、Scene View の表示を軽くします。

1. USD を選び、右クリックの **Generate Selected Proxies...** を実行します。`.usdz` にも使えます。
2. ダイアログで、メッシュ1つあたりの目標の三角形数（既定は300）を指定します。

**Libraries...** の **Generate Missing Proxies...** を使うと、表示中の条件に合う USD にまとめて追加できます。処理は別のプロセスで行うので、その間も Houdini を操作できます。

できあがる proxy の特徴は次のとおりです。

- 形が大きく崩れないように、元の形状を保ったまま面を減らします。
- 穂先の小花や種のような小さなばらばらの部品は、近くにあるものをまとめて1枚の板に置き換えます。板は部品が並ぶ面に沿わせ、元の色の平均で塗ります。小さな部品が何千もある植物でも proxy が軽くなります。
- 元のメッシュにベースカラーのテクスチャが設定されていれば、その色を proxy の頂点カラーに焼き込みます。proxy だけを表示していても、おおよその色が分かります。
- proxy が持つのは形と色だけです。UV・法線・不透明度は持ちません。
- 形状をバリアントで切り替える USD では、すべてのバリアントに proxy を作り、proxy も一緒に切り替わります。

**この機能は USD ファイル自体を書き換えます。** 書き換える前に、元のファイルを `data/backups/proxy/` にバックアップします。変更するのは素材の入口ファイルだけで、参照先の別ファイルには触れません。すでに proxy を持つ USD や、メッシュを含まない USD はスキップします。

## 複数オブジェクト入り USD を1つずつ切り替える

配布されている素材パックには、品種違いのきのこ数体のように、独立したオブジェクトが同じ位置に重なって入っているものがあります。そのまま配置すると、全部が重なって表示されます。

この機能を使うと、中のオブジェクトを1つずつ表示できるようになります。

1. USD を選び、右クリックの **Generate Selected Element Switch...** を実行します。
2. `element` という名前のバリアントセットが追加され、各オブジェクトが `Element0`、`Element1`… というバリアントになります。最初は `Element0` だけが表示されます。

バリアントセットは配置したプリムに付くので、次のどの方法でも切り替えられます。

- **Stage Manager**: 配置したプリムを選び、右の Inspector の **Variant Sets** にある `element` から選びます。
- **ドラッグ&ドロップ / Import Selected**: 自動で追加される **Set Variant** ノードで選びます。
- **手動**: **Set Variant** ノードを追加し、Primitives に配置したプリム（例: `/assets/資産名`）、Variant Set に `element`、Variant Name に `Element0` などを指定します。

**この機能は、代わりのオブジェクトが複数入ったパックにだけ使ってください。** 手すりの部品集のように、全部そろって1つの物になるキットも、ファイルの構造は同じに見えるため区別できません。誤って使うと、キットの大半が非表示になります。このため、まとめて生成する機能はあえて用意していません。

ほかにも次のように動きます。

- 生成すると `variant` タグが付き、サムネイルの左上に「VARIANT」バッジが出ます。
- 間違えて生成した場合は、右クリックの **Delete Element Switch** で生成前の状態に戻せます。
- 変更前のファイルは `data/backups/element/` に保存されます。
- 古いバージョン（0.19.0 より前）で生成した USD は、Stage Manager の Inspector に切り替えが出ません。もう一度 **Generate Selected Element Switch...** を実行すると直ります。

## LOD（距離に応じて詳細度を切り替える）

USD に、ポリゴン数を減らした段階（LOD）を追加します。Houdini の Create LOD LOP と同じ形で作るので、Houdini 標準のノードで切り替えられます。

1. USD を選び、右クリックの **Generate Selected LODs...** を実行します。
2. ダイアログで段数（2〜9、既定は4）と、1段ごとに残す割合（既定は50%）を指定します。

たとえば4段・50%なら、`LOD_1`（元のまま）、`LOD_2`（1/2）、`LOD_3`（1/4）、`LOD_4`（1/8）ができます。**Libraries...** の **Generate Missing LODs...** を使えば、LOD のない USD にまとめて追加できます。

LOD は、配置したプリムに付く `LOD` という名前のバリアントセットとして追加されます。切り替え方は次の3つです。

- **Auto Select LOD** LOP: カメラからの距離で自動的に切り替えます。
- **Stage Manager**: 配置したプリムの Inspector にある **Variant Sets** から選びます。
- **Set Variant** LOP: Variant Set に `LOD`、Variant Name に `LOD_2` などを指定して固定します。

`lod` タグの付いた USD をドロップすると、Auto Select LOD ノードが自動で追加されます。切り替わる距離は素材の大きさから仮に決めているので、シーンに合わせて調整してください。カメラは上流にあるものを使い、見つからなければ `/cameras/camera1` を指定します。

元のメッシュは変更しません。各段では、面を減らしたメッシュを隣に作り、元のメッシュを非表示にします。UV とマテリアルの割り当ては引き継ぎます。追加済みの proxy や Element Switch はそのまま使えます。

生成すると `lod` タグが付き、サムネイルに「LOD」バッジが出ます。**Delete LODs** で生成前の状態に戻せます。変更前のファイルは `data/backups/lod/` に保存されます。すでに LOD を持つ USD はスキップするので、段数を変えたいときは先に Delete LODs を実行してください。

## 風に揺れるアニメーションを作る

植物の USD から、風に揺れる版の USD を別の素材として作ります。元の USD は変更しません。

1. 植物の USD を選び（複数可）、右クリックの **Generate Wind Animation...** を実行します。
2. ダイアログで強さとループの長さを指定します。強さ 1 がそよ風で、2〜3 にすると風の強い日の揺れになります。ループは既定で10秒です。
3. 完了すると自動で再スキャンし、`<名前>_Anim` という素材が一覧に加わります。サムネイルは元の素材の画像を使います。

できる素材の特徴は次のとおりです。

- 揺れは途切れずにループします。フレーム 1 から始めても 1001 から始めても、どのフレームでも揺れ続けます。
- 特定の方向から吹く風ではなく、周りからなんとなく風を受けているような揺れです。インスタンスで向きをばらばらに置いても不自然になりません。
- 茎の途中から出た葉や穂の小花は、付いている茎と一緒に動きます。根元と地面に広がる根は動きません。
- 元の素材の LOD・バリアント・proxy はそのまま使えます。Scene View では proxy も一緒に揺れます。Point Instancer のプロトタイプにしても揺れます。
- 小さな株ほど揺れは控えめになります。

Point Instancer では、同じプロトタイプのインスタンスはすべて同じタイミングで揺れます。株の種類（`variant`）ごとに揺れ方は違いますが、同じ株をたくさん並べる場合は、`wind_phase` バリアント（`phase_0`〜`phase_3`、ループを4分の1ずつずらしたもの）を変えたプロトタイプを用意すると、揃って揺れるのを防げます。

保存されるファイルは `<名前>_Anim.usd` と、その隣の `anim/<名前>_Anim_clip.usd` の2つです。`<名前>_Anim.usd` は元の USD を参照するので、元の USD と同じフォルダー構成のまま使ってください。フォルダー名と同じ名前の USD（パッケージ）や `.usdz` から作った場合は、隣に `<名前>_Anim` フォルダーを作ります。この場合、元の素材だけを別の場所へ移動すると参照が切れます。

作り直すと、前のファイルは `data/backups/anim/` に保存されます。Houdini のシーンで読み込んでいる間は置き換えられないことがあるので、その場合はシーンから外してから実行してください。

`<名前>_Anim` の素材には proxy・LOD・Element Switch を追加できません。必要な場合は元の素材に追加してから、アニメーションを作り直してください。木のように幹と枝の揺れ方が大きく違うものは想定していません。

## タグとバッジの自動付与

USD がバリアントセット・proxy・アニメーションを持っているかを調べて、タグとサムネイルのバッジを自動で付けます。このツールで追加したものに限らず、配布元で最初から入っているものも対象です。

| USD の状態 | タグ | バッジ |
|---|---|---|
| 名前が `LOD` で始まるバリアントセットがある | `lod` | LOD（橙） |
| それ以外のバリアントセットがある | `variant` | VARIANT（青） |
| proxy の形状がある | `proxy` | PROXY（緑） |
| アニメーションしている | `anim` | ANIM（紫） |

該当しなくなったタグは自動で外れます。自分で付けたタグはそのまま残ります。調べるのは、再スキャンやパネルを開いたときに見つかった新しい USD と、変更された USD だけです。

## Asset Catalog

- 左下の **Catalog** 選択欄で、登録先のカタログを選びます。素材フォルダーの `Catalog` フォルダーにあるデータベースは自動で見つかります。選択欄を右クリックすると、**Open Catalog** / **Select Catalog...** / **New Catalog...** が使えます。
- USD を選んで右クリックの **Add Catalog** で登録します。複数をまとめて登録できます。同じパスは二重に登録されません。
- 右クリックの **Publish Static USD...** は、素材の現在のフレームを USD として書き出します。元の画像への参照はそのまま残るので、共有するときは画像も一緒に渡してください。

**Open Catalog** を押すと、Asset Catalog のパネルを開く手順が表示されます。Houdini 22.0.447 には、スクリプトからこのパネルを開くと Houdini のメニューが反応しなくなる不具合があるため、自動では開きません。表示された手順に従い、Asset Catalog パネルのメニューにある **Open Asset Database File...** から、表示されたパスのデータベースを開いてください。

## 素材が多いとき

10万件を超える素材でも軽く動くように作っています（約11万ファイルのテスト用ライブラリーで確認しました）。

- 一覧にページ送りはありません。下へスクロールすると続きを読み込みます。画面の近くにある素材の画像だけをメモリーに持つので、スクロールしてもメモリー使用量は増え続けません。
- フォルダーの切り替えや検索は、素材の数にかかわらずすぐに結果が出始めます。
- スキャン・サムネイル生成・情報の取得・proxy の生成は、別のプロセスで優先度を下げて実行します。大量に生成している間も、パネルの操作は妨げられません。
- 大きな画像（2MB超）は、サムネイルができるまで仮の画像で表示します。
- `Ctrl+A` で選択されるのは、読み込み済みの素材だけです。

エクスプローラーで素材やフォルダーを追加・移動・削除した場合は、Rescan を押してください。

## 設定とデータ

`data` フォルダーには次のものを保存します。

| ファイル | 内容 |
|---|---|
| `settings.json` | PCごとの設定（アイコンの大きさ、まとめ表示の設定など） |
| `library.sqlite3` | 素材の索引、タグ、お気に入り |
| `thumbnails/` | テクスチャの縮小画像 |
| `backups/` | 移動や USD の書き換えの前に取ったバックアップ（種類ごとのフォルダーに保存） |

素材フォルダーを別の場所へ移したときは、**Libraries...** → **Relink Library...** で新しい場所を指定してください。新しいライブラリーとして追加し直すと、これまでのタグやお気に入りは引き継がれません。

## うまくいかないとき

- **素材が表示されない**: 素材が `USD` / `Texture` / `3DModel` の下にあるかを確認し、Rescan を押してください。USD は、フォルダーと同じ名前の入口ファイルが必要です。
- **サムネイルが作れない**: Houdini と Karma のライセンス、素材フォルダーへの書き込み権限を確認してください。読み込めない形状や、依存するファイルが欠けている素材はエラーになります。
- **サムネイルが白っぽい**: HDRI が見つからず、白い Dome Light で照らしています。「サムネイル」の節を参考に HDRI を置いてください。
- **ドロップしても何も起きない**: 対応していない場所に落としています。「ドラッグ&ドロップ」の表で落とせる場所を確認してください。
- **DirectX の法線マップでエラーになる**: 法線マップを OpenGL 形式に変換してください。
